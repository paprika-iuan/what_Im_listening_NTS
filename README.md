# What I'm Listening on NTS
*A little card to give personality to my GitHub Page*

Based on [que escolto](https://que-escolto.eina.workers.dev/player) by my dear friend [encarbassotnopot](https://github.com/encarbassotnopot), I've built a small widget that displays a card with the latest episode from one of my favorite NTS shows.

I tried to keep the same style they use for displaying shows on the web and in the app.

**Note:** Clicking the card redirects to GitHub's Camo proxy (their image caching layer). From there, you can click the NTS logo to go to their homepage, the cover image to reach the episode, or the play button to visit the SoundCloud page.
